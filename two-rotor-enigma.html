Principles and scope

This page uses a two-rotor teaching model. It is intentionally explicit about which parts are fixed wires and which parts move.

Fixed wiring vs. window

Rotor I and Rotor II each contain a fixed 26-letter permutation. Their window letters only change which frame letter meets the fixed internal contacts. They do not create a new wiring table.

Two-rotor stepping

Rotor I steps before every letter. When its resulting window is A, Rotor II steps at the same instant. This is the specific notch rule selected for this demonstrator, rather than a reproduction of all historical Enigma stepping variants.

Why encryption also decrypts

The plugboard is bidirectional, the reflector pairs letters, and the return route uses each rotor in reverse. With the same initial windows and plugboard, applying the machine again recovers the input.

Signal order

Keyboard → plugboard → Rotor I → Rotor II → reflector → Rotor II in reverse → Rotor I in reverse → plugboard → lampboard. The animation uses exactly this order.
